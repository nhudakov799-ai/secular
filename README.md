# SECULAR — сайт

Одностраничный сайт телеграм-канала [SECULAR](https://t.me/SecularRussia): доставка брендовых вещей с зарубежных онлайн-площадок (США, Китай, Южная Корея, Япония, Евросоюз) в Россию.

- Оформление заказа: [@BalenciagaPariz](https://t.me/BalenciagaPariz)
- Канал: [@SecularRussia](https://t.me/SecularRussia)

## Как устроен

Весь сайт — один файл `index.html` (HTML, CSS и JavaScript внутри, без сборки). Есть мобильная версия.

## Публикация через GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)` → Save.
Через 1–2 минуты сайт будет доступен по адресу `https://<имя-аккаунта>.github.io/<имя-репозитория>/`.
